TravelPlanner

A comprehensive full-stack travel planning platform built with Python, Flask, and SQLite. Features manual Weighted Graph data structure, Dijkstra's algorithm for shortest road routing, and a transparent multi-factor recommendation engine.

BCA / B.Tech Data Structures & Algorithms Project

Core Algorithms

  • Weighted Graph (Adjacency List)
  • Dijkstra's Shortest Path Algorithm
  • Content-Based Recommendation
  • Dynamic Day-Wise Scheduler

Quick Navigation

  • Home Landing Page
  • Travel Questionnaire
  • Explore Destinations
  • Route & Distance Finder
  • Travel History & Profile

Project Information

Python 3 Flask SQLite Leaflet.js Min-Heap O((V+E)logV) No Paid APIs

All road networks, attractions, and reviews run on local seed data.
